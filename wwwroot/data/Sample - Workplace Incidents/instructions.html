Sample Project: Workplace Incidents

This is a demo corpus showing the more advanced configuration options: the constrained suggestion workflow, a context panel built from extra input columns, and an external system link.

What to annotate

  • Cause — the action or condition that caused the incident
  • Body Part Affected — the part of the body injured, if any
  • Location — where in the workplace the incident happened
  • Severity — how serious the outcome was

Constrained annotation

This corpus sets suggestionsConfineAnnotations: true, so you can only annotate the spans an AI model has already proposed. Pick a span type, then click anywhere in the text: a dropdown lists every suggested span overlapping that point, and hovering previews it in your selected color. There's no free-text selection here — that's the point of this mode, it keeps annotations aligned to a fixed set of candidate boundaries.

Context panel

The record's Department, Reported Date, and the severity the reporter originally logged are shown in a "Context" tile above the text, pulled straight from extra columns in input.csv via recordContextTemplate. This is useful for giving annotators background info that isn't part of the text itself.

External link

The ↑ icon next to the Record ID opens a (placeholder) link to an external incident-management system for that record, built from externalLinkURL.
